# Ollama 連携設定手順

Thunderbird アドオンからローカルの Ollama を呼び出すために、以下の設定を行ってください。

## 1. 日本語対応モデルのインストール
Ollama が起動している状態で、PowerShell 等で以下を実行してください。

おすすめのモデル（VRAM 12GB の場合）：
- **Gemma 3 12B**（最新モデル、非常に高品質）: 
  ```powershell
  ollama pull gemma3:12b
  ```
- **Gemma 2 9B**（動作が軽快でバランスが良い）: 
  ```powershell
  ollama pull gemma2
  ```

※お使いの PC スペック（VRAM 12GB）であれば、最新の **gemma3:12b** が問題なく動作し、非常に高い要約精度が期待できます。

## 2. Windows 環境変数の設定 (CORS 許可)
アドオン（ブラウザ）から Ollama へのアクセスを許可するために必須の設定です。

1. **スタートメニュー**を開き、「**環境変数**」と入力します。
2. 「**システム環境変数の編集**」を選択します。
3. 表示されたウィンドウの右下にある「**環境変数**」ボタンをクリックします。
4. 「**ユーザー環境変数**」欄の「**新規**」をクリックします。
5. 以下を入力して「OK」を押します：
   - 変数名: `OLLAMA_ORIGINS`
   - 変数値: `*`
6. 全てのウィンドウを「OK」で閉じます。

## 3. Ollama の起動と再起動
- **起動方法**: 通常はインストール時にスタートアップに登録されるため、タスクトレイ（時計の横）に **Ollama のアイコン（ラマのマーク）** があれば起動しています。
- **再起動**: 環境変数を反映させるため、タスクトレイのアイコンを**右クリック → Quit Ollama** で一度終了し、再度スタートメニューから **Ollama** を起動してください。
- **コマンドラインから実行する場合**: サーバーとして起動させるには `ollama serve` を使用しますが、通常はトレイアイコンから起動させておけば OK です。

---
設定完了後、アドオンをリロードして実行してください。
コンソール（Ctrl+Shift+J）にエラーが出る場合は、環境変数が正しく反映されているか確認してください。
